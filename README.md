# Gulls Video Converter

Desktop app for Windows (10/11, 64-bit). Three tools:

1. **HTML > Video**: render HTML motion graphics to MP4, WebM, GIF or PNG frames.
2. **Shrink GIF**: make GIFs light enough to send by email.
3. **Fix for iPhone**: make videos save to the iPhone camera roll, with no quality loss.

## Install

1. Go to **[Releases](../../releases/latest)** and download `Gulls-Video-Converter-Setup-<version>.exe`.
2. Run it. It installs in a few seconds and opens the app. No admin rights needed.
3. Windows may show **"Windows protected your PC"** because the installer isn't code-signed yet.
   Click **More info**, then **Run anyway**.

## Updates

The app checks for new versions when it opens. When one is available, a green banner shows
what's new: click **Download**, then **Restart & install**. You can also click
**Check for updates** at the bottom of the window.

Requires Google Chrome or Microsoft Edge (Edge comes with Windows) for the HTML > Video tool.
